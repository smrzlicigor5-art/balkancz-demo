# BalkanCZ Problem-First Triage Demo

Mobile-first React + Tailwind demo centered on life events and document triage rather than an expert directory.

## Included
- dominant drag-and-drop document upload UI
- clickable life-event problem cards
- 3-tier service model
- fixed-price quick fixes
- interactive triage modal for “Rodilo mi se dijete”
- Escape/overlay modal closing
- demo order/upload feedback
- required footer disclaimer

Open `index.html` in a modern browser with internet access. React, Babel, Tailwind and Lucide are loaded via CDN.

No file is actually uploaded and no payment is processed.
